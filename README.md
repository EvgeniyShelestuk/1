# LumaFit AI

LumaFit AI is a responsive landing page for an AI-powered fitness coach. The product concept focuses on busy people who want personalized 15-minute workouts, habit tracking, and simple daily guidance.

## Concept

The brand direction is clean, practical, and motivating. The website combines a health-tech SaaS layout with fitness app visuals: a dashboard preview, adaptive workout features, habit streaks, pricing cards, and a short testimonial/results section.

## Run Locally

Open `index.html` in a browser, or run a simple static server:

```bash
python -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## AI Workflow

1. NanoBanana was used to create two design iterations.
2. The second iteration was selected as the development reference because it had stronger layout structure, clearer responsive behavior, and better section coverage.
3. dev0 can be used with the prompt in `docs/prompts.md` to generate or refine the website and connect the project to GitHub.
4. VEO3 and Suno prompts are documented in `docs/prompts.md`.
